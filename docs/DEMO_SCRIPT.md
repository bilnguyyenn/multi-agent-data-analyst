# 90-second portfolio demo script

An [interactive 90-second walkthrough](../examples/retail-walkthrough.html) packages
six recorded browser states with explicit presentation pacing. It is not a
real-time performance recording or a participant study. Download and open the
self-contained HTML locally. The storyboard below can also be used for narration.
Run `sh scripts/run_local_demo.sh` and open the printed operations URL.

| Time | Show | Explain |
|---|---|---|
| 0–15s | Two source snapshots and the weekly playbook | Historical real data, explicit definitions, immutable content hashes |
| 15–30s | First completed review; country/period filters and KPI table | Net sales, cancellation value, invoice denominator, and known-ID limitations |
| 30–45s | Expand a computation and open the full ledger entry | Every displayed number resolves to a query, parameters, transformation, and source |
| 45–60s | Open the second review and compare periods | Same definition fingerprints, fresh data, and descriptive contribution differences |
| 60–75s | Download HTML and inspect the linked computation | Portable evidence and caveats without the server or a model |
| 75–90s | Show verification/evaluation status | Historical scorecards reproduce; 140 deterministic checks; local-model and participant results are pending |

For the generic agent/follow-up portion, use a separately labeled recorded/replay
run with a configured sandbox. Do not present scripted behavior as live-model
accuracy. Capture a real recording when convenient; avoid implying external users
or measured savings before the prepared pilot has been conducted.
